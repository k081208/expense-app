# Supabase

`migrations/` に SQL マイグレーションを置きます（**STEP 2 で作成**）。

予定しているテーブル:

| テーブル | 役割 |
| --- | --- |
| `profiles` | `auth.users` に 1:1 で対応するユーザー情報 |
| `cards` | 登録カード（カード会社・表示名・下 4 桁・支払日・取得方法・有効/無効） |
| `billing_records` | 請求情報（金額・支払日・取得元・取得日時・成功/失敗） |
| `connections` | Google / 各種 API の連携情報（トークンは暗号化して保存） |
| `fetch_logs` | 取得の実行履歴（失敗理由の確認用） |

すべてのテーブルで **Row Level Security を有効化**し、
`auth.uid() = user_id` のポリシーによって他ユーザーのデータが見えないようにします。

保存しないもの: **カード番号の全桁 / セキュリティコード(CVV) / カード会社のログインパスワード**。
カード番号は下 4 桁 (`cards.last_four`) のみ任意で保存します。
